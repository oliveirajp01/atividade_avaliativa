# atividade_avaliativa

Passar nessas validações do código não significa que a senha é 100% segura, já que alguém ainda pode adivinhar combinações simples como Senha123.
O nosso programa só checa regras básicas de formato, mas não descobre se a senha é fraca ou se já foi vazada na internet.
Como desenvolvedores, o nosso papel não é só travar o usuário com regras chatas, mas sim ensinar como criar senhas melhores. 
Para deixar o sistema seguro de verdade, precisamos de usar recursos mais avançados, como a autenticação em dois fatores (2FA).
